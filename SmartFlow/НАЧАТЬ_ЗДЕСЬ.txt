SMARTFLOW — ПРОТОТИП И ПРЕЗЕНТАЦИЯ

1. Распакуйте весь архив.
2. Для презентации откройте SmartFlow_MVP.pptx (редактируемая) или SmartFlow_MVP.pdf.
3. Для приложения откройте папку prototype.
   Windows: установите Python 3.10–3.13, затем запустите start_windows.bat.
   macOS/Linux: выполните bash start.sh в терминале из этой папки.
4. После запуска откройте в браузере http://127.0.0.1:8000.
5. Нажмите встроенный пример счёта: проверка → согласование → CSV.

Первая установка зависимостей требует интернет. Само приложение работает локально.
Подробности и устранение проблем: prototype/README.md.
Постановка MVP, модель данных и критерии пилота: Модель_MVP.md.

Прототип проверен в Linux / Python 3.12 / Chromium. Сценарии Windows и macOS
подготовлены, но на этих ОС не запускались. Презентация проверена экспортом
LibreOffice Impress; PowerPoint в этой среде не запускался.

Данные примеров вымышленные. В архиве нет заполненной базы: первый запуск чистый.
Снимки приложения показывают демонстрацию обоих маршрутов согласования.
